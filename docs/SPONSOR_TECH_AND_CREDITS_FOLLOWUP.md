2. Use them for experiments that strengthen an existing InnerOS capability or reduce operating cost.
3. Keep production-critical reasoning, governance, permits, and evidence functional without the sponsor service.

5. Review credits before expiration and either use them for a scoped experiment or deliberately let them expire rather than creating unnecessary dependencies.
